# Blog Customizer

**Blog Customizer** — это интерактивное приложение для настройки внешнего вида статьи в блоге. Проект демонстрирует навыки управления состоянием формы и страницы, работу с CSS-переменными и разработку компонентов по методологии Storybook.

---

## О проекте

**Идея проекта:** Создать удобный инструмент, который позволяет пользователю в реальном времени изменять визуальное оформление статьи (шрифт, размер, цвета, отступы) через панель настроек.

**Решаемая проблема:** Приложение показывает, как правильно организовать композицию компонентов, управлять временным состоянием формы и применять изменения только после явного подтверждения пользователя, избегая нежелательных «скачков» интерфейса.

**Что я сделал / Моя роль:**
*   Разработал **компонентную архитектуру** приложения, используя подход "умных" и "глупых" компонентов.
*   Реализовал **логику открытия/закрытия** сайдбара с настройками.
*   Организовал **раздельное хранение состояния**: текущее состояние страницы и "черновик" состояния в форме, что позволяет применять изменения только по нажатию кнопки «Применить».
*   Внедрил механизм **управления CSS-переменными** через React-состояние для динамической смены стилей.
*   Настроил **Storybook** для документирования и изолированной разработки UI-компонентов.
*   Настроил **линтеры и форматтеры** (ESLint, Stylelint, Prettier) и **Git хуки** (Husky) для поддержания качества кода.

**Стек технологий:**
*   **Frontend:** React 18, TypeScript
*   **Styling:** CSS Modules, CSS Variables
*   **Компоненты:** Storybook
*   **Качество кода:** ESLint, Stylelint, Prettier, Husky
*   **Сборка:** Webpack

## Установка и запуск

Эти инструкции помогут вам развернуть проект локально для разработки или тестирования.

### Требования
- **Node.js** версии 16 или выше
- **npm** или **yarn**

### Шаги по установке

1.  **Клонируйте репозиторий:**
    ```bash
    git clone https://github.com/daniloann/blog-customizer.git
    cd blog-customizer
    ```

2.  **Установите зависимости:**
    ```bash
    npm install
    # или
    yarn install
    ```

3.  **Запустите приложение в режиме разработки:**
    ```bash
    npm run dev
    # или
    yarn dev
    ```
    Откройте `http://localhost:3000`, чтобы увидеть результат.

### Дополнительные команды

*   **Запуск Storybook** (для просмотра и тестирования компонентов):
    ```bash
    npm run storybook
    ```
*   **Запуск линтера для стилей:**
    ```bash
    npm run stylelint
    ```
*   **Запуск ESLint:**
    ```bash
    npm run lint
    ```
*   **Запуск форматтера Prettier:**
    ```bash
    npm run format
    ```

## Как это работает (ключевые сценарии)

1.  **Открытие сайдбара:** Пользователь нажимает на кнопку-«стрелку», которая открывает панель с настройками. Повторное нажатие или клик вне сайдбара закрывает его.
2.  **Редактирование настроек:** Внутри сайдбара пользователь изменяет параметры оформления (например, размер шрифта или цвет фона). Важно: изменения не применяются к статье мгновенно.
3.  **Применение изменений:** После того как все настройки выбраны, пользователь нажимает кнопку «Применить». Только в этот момент стили (через CSS-переменные) применяются к отображаемой статье.
4.  **Сброс настроек:** При нажатии кнопки «Сбросить» все значения в форме возвращаются к исходным (тем, что были при загрузке страницы), и эти изменения немедленно применяются к статье.

## Планы по доработке (Roadmap)

Проект развивается, и вот что я планирую улучшить в ближайшее время:

- [ ] **Добавить валидацию полей:** Например, проверять, чтобы размер шрифта не выходил за разумные пределы (не менее 8px и не более 72px).
- [ ] **Расширить набор настроек:** Добавить возможность менять цвет текста, подложки, отступы между абзацами, а также выбрать тип шрифта из списка.
- [ ] **Внедрить сохранение настроек:** Использовать `localStorage` для сохранения последних применённых настроек, чтобы они не сбрасывались после перезагрузки страницы.
- [ ] **Улучшить UX:** Добавить анимацию открытия и закрытия сайдбара для более плавного взаимодействия.
- [ ] **Покрыть проект тестами:** Написать unit-тесты для ключевой логики (управление состоянием, применение стилей) с помощью Jest и React Testing Library.
- [ ] **Оптимизировать перерисовки:** Использовать `React.memo` и `useCallback` для компонентов, которые часто обновляются, чтобы повысить производительность.
